# Manga Learn JP

A Next.js application for learning Japanese from manga pages, PDF-derived Mokuro output, and AI-assisted sentence analysis.

## Current Features

- **Image Analyzer**: Upload a manga image and let the app choose the best analysis path automatically.
- **Single-page image pipeline**: Sentence-location detection first, then full-page OCR and analysis as the fallback.
- **Mokuro Reader**: Load a Mokuro output directory directly in the browser, including the `.mokuro` file and page images.
- **Clean Mokuro overlays**: OCR text is not rendered over the image. Clickable boxes stay on the page image and analysis appears in the side panel.
- **Batch page analysis**: Analyze every text block on the current Mokuro page in one action.
- **Persistent Mokuro cache**: Saves analysis to `mokuro-analysis-cache.json` in the selected directory when browser write access is available, with a localStorage fallback.
- **Chinese and English explanations**: Mokuro analysis supports both languages and defaults to Chinese.
- **N5/basic filtering**: Basic JLPT N5 vocabulary and grammar are omitted from learner-facing analysis by default.
- **OpenAI-compatible providers**: Use OpenAI directly or any OpenAI-format endpoint such as Ollama, LM Studio, vLLM, or hosted compatible APIs.
- **Colab Mokuro conversion helper**: Convert PDFs remotely through Google Colab and download a ready-to-import Mokuro zip.

## Main Modes

### Image Analyzer

The default mode is `Image Analyzer`. It accepts PNG, JPG, JPEG, WebP, and BMP images up to 10 MB.

When you click **Analyze Image**, the app tries:

1. AI sentence-location detection for interactive reading boxes.
2. General full-page OCR and text analysis as the fallback.

The UI renders a single-page workspace: the image stays on the left, and the simplified translation, N4+ vocabulary, and grammar analysis appear on the right. Chinese and English explanations are supported, with Chinese as the default.

### Mokuro Reader

Use `Mokuro Reader` for `.mokuro` output generated by Mokuro.

Expected directory contents:

```text
spy6.mokuro
spy6/page-001.jpg
spy6/page-002.jpg
...
```

The reader will:

- Match Mokuro pages to local images.
- Display clickable OCR boxes without drawing the OCR text over the image.
- Analyze clicked text blocks on demand.
- Reuse cached analysis when the same block has already been analyzed.
- Batch analyze all text blocks on the current page.
- Save results to `mokuro-analysis-cache.json` when possible.

## PDF to Mokuro Conversion

This repo includes a helper script for running Mokuro remotely on Google Colab:

```bash
scripts/process-mokuro-colab.sh INPUT.pdf [OUTPUT.zip]
```

Prerequisites:

```bash
uv tool install google-colab-cli
```

Useful environment overrides:

```bash
COLAB_GPU=T4
COLAB_DPI=220
COLAB_SESSION_NAME=mokuro-spy6
COLAB_KEEP_SESSION=1
```

The output zip contains:

```text
<volume>.mokuro
<volume>/page-001.jpg
_ocr/<volume>/*.json
```

Unzip the archive and select the output directory in `Mokuro Reader`.

## AI Provider Configuration

At least one provider must be configured.

### OpenAI

```bash
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-4-vision-preview
```

### OpenAI-Format API

```bash
OPENAI_FORMAT_API_URL=http://localhost:11434/v1
OPENAI_FORMAT_API_KEY=optional-api-key-if-required
OPENAI_FORMAT_MODEL=llava:latest
```

Examples:

- Ollama: `http://localhost:11434/v1`
- LM Studio: `http://localhost:1234/v1`
- vLLM or compatible hosted APIs: your OpenAI-compatible `/v1` endpoint

## API Overview

### `POST /api/analyze`

Supports:

- Text analysis: `text`, `analysisLanguage`, `excludeN5`.
- Image analysis: `imageBase64`, `provider`, plus optional mode flags used internally by the UI.
- Reading boxes: `readingMode: true`.
- Legacy/internal panel routes: `simpleAnalysisMode: true` and `mangaMode: true`. These are not used by the current Image Analyzer UI.

Current provider values:

```ts
type AIProvider = 'openai' | 'openai-format'
```

## Notes for Development

- Keep secrets in `.env.local` or deployment environment variables.
- Update `.env.example` when adding new provider or model settings.
- Run `npm test`, `npm run lint`, and `npm run build` before shipping changes.
- When editing mirrored runtime code under `src/lib`, check whether `netlify/src/lib` needs the same change.
