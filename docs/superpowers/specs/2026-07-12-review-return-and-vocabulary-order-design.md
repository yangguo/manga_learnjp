# Review Return And Vocabulary Order Design

日期: 2026-07-12
状态: 已完成

## 目标

解决两个阅读流程问题：

1. 从阅读页进入复习后，用户可以在复习过程中或完成后返回，并恢复进入复习前的完整阅读状态。
2. 分析面板中的词汇不再按 JLPT 目标等级分组，而是严格按照当前选中文本的分析顺序平铺显示。

语法区域继续使用基础、重点、超纲、未定级四组；M4 的 FSRS 调度、复习评分、词汇收藏与 JLPT 徽标保持不变。

## 根因

首页的 Mokuro 目录句柄、当前页、选中文字、分析结果和滚动位置主要保存在 `Home` 与 `MokuroReader` 的 React 内存状态中。现有复习入口跳转到独立 `/review` 路由，复习完成后的“返回阅读”又直接链接 `/`。重新进入首页会重建阅读组件，无法恢复不可序列化的目录句柄和完整界面状态。

词汇分组则集中在 `MokuroAnalysisPanel`：分析结果先按句子展平，随后经过 `groupVocabularyByTarget` 重排为四组。这改变了提供者返回的文本顺序。

## 方案决策

从首页阅读界面启动复习时，使用当前页面内的全屏复习层，不发生路由跳转。阅读组件继续挂载在复习层下方，因此目录句柄和全部本地状态保持原对象与原值。关闭复习层后直接显示原阅读界面。

不采用以下方案：

- 仅调用浏览器后退：Next.js 页面重挂载仍可能丢失内存状态，无法保证目录句柄恢复。
- 将全部阅读状态迁移到全局持久化存储：改动范围过大，且浏览器文件系统句柄不能可靠序列化。

独立 `/review` 路由继续保留，供 `/words` 页面和直接访问使用。

## 组件边界

### Home

- 新增是否显示复习层的本地状态。
- 向 `Header` 和 `WordBankDrawer` 传入启动复习回调。
- 在现有阅读 DOM 之后渲染固定定位的全屏复习层。
- 复习层打开时锁定背景滚动；关闭后恢复原滚动位置和阅读组件状态。

### Header

- 新增可选 `onOpenReview` 回调。
- 首页提供回调时使用按钮打开复习层。
- 其他页面未提供回调时继续链接 `/review`。

### WordBankDrawer / WordBank

- 透传可选 `onStartReview` 回调。
- 阅读页抽屉中点击“开始复习”时先关闭抽屉，再打开复习层。
- 独立 `/words` 页面继续链接 `/review`。

### ReviewSession

- 新增可选 `onExit` 回调和退出文案。
- 内嵌模式在复习进行中、加载失败和复习完成时均提供“返回阅读”。
- 退出只关闭复习层，不重置队列之外的阅读状态。
- 独立路由继续提供返回生词本；直接访问时不依赖不存在的阅读回调。

### MokuroAnalysisPanel

- 词汇按 `analysisResult.sentences` 的顺序遍历。
- 每句内部按 `sentence.words` 的原顺序遍历。
- 不排序、不去重、不按 JLPT 等级分组。
- 移除词汇区的目标等级选择器和四个词汇分组标题。
- 每张词汇卡继续显示 JLPT 徽标、释义、词性和收藏按钮。
- 语法目标等级选择和四组展示保持不变；目标等级选择器移到语法区域。

## 数据与状态

不新增持久化 schema。复习层只控制展示状态；词汇和复习卡仍由 `word-bank-storage` 管理，Mokuro 阅读进度仍使用现有 `mokuro-progress`。退出复习层不会清空、重建或重新导入阅读数据。

词汇顺序由一个纯函数表达并测试：输入分析结果，返回按句子和句内顺序展平的新数组，且不修改输入。

## 可访问性与交互

- 全屏复习层使用对话框语义并具有明确标题。
- 打开时焦点进入复习层；关闭后焦点返回触发入口。
- `Escape` 可返回阅读，但评分提交过程中不打断正在写入的结果。
- 复习层具有独立滚动区域，375px 宽度下不产生横向溢出。
- 返回按钮在复习进行中和完成状态始终可见，不要求先完成所有卡片。

## 错误处理

- 复习数据加载失败时仍可返回阅读。
- 评分写入失败沿用现有 toast，并保持当前卡片，不自动关闭复习层。
- 若首页没有复习词，复习层显示现有完成/空队列状态并允许立即返回。
- 背景滚动锁必须在组件卸载或异常退出时恢复。

## 测试与验收

自动测试：

- 词汇严格保持句子顺序和句内顺序。
- 顺序 helper 不修改输入，未定级词汇也不会被过滤。
- 首页复习入口选择内嵌模式，独立页面保持路由模式。
- `ReviewSession` 在进行中、失败和完成状态均暴露退出动作。

浏览器验收：

1. 在 Mokuro 阅读中定位到非首页页码并选择一个文字框。
2. 从 Header 和收藏抽屉分别进入复习。
3. 复习中返回，确认目录仍加载、页码、选中文字、分析结果和滚动位置不变。
4. 完成复习后返回并重复确认。
5. 验证词汇卡按选中文本顺序显示，等级不同也不重排。
6. 在桌面和 375px 视口验证无重叠或横向溢出。

## 完成定义

- 阅读页进入和退出复习不卸载阅读组件，完整状态可恢复。
- 复习过程、错误状态和完成状态都可返回阅读。
- 词汇严格按选中文本分析顺序平铺，语法分组保持原行为。
- 独立 `/review` 和 `/words` 工作流无回归。
- 单元测试、lint、生产构建与浏览器验收全部通过。
