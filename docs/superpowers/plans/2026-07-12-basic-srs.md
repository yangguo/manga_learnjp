# M4 Basic SRS Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为已收藏词汇增加基于 FSRS 的本地每日复习队列、四档评分和持久化复习页面。

**Architecture:** `src/lib/srs.ts` 隔离 `ts-fsrs` 与应用 DTO，纯函数生成每日队列和调度结果；`word-bank-storage` v3 原子保存词汇与 reviewCards；`ReviewSession` 只通过 store actions 开始会话和评分。

**Tech Stack:** TypeScript、React 19、Next.js App Router、Zustand persist、Vitest、ts-fsrs 5.4.1、Tailwind、Playwright。

**Validated design:** `docs/superpowers/specs/2026-07-12-basic-srs-design.md`
