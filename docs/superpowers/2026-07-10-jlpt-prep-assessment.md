# JLPT 备考能力评估与开发路线图

日期: 2026-07-10
最后更新: 2026-07-11
状态: M2B 已完成 / 当前阶段 M3 下一步

## 一、产品定位

`manga_learnjp` 的核心仍是「漫画阅读 + 按需 AI 讲解」。JLPT 能力建设服务于真实语境下的词汇积累和复习,不把产品扩张成覆盖听力、模拟考试、账号和课程体系的完整备考平台。

当前路线优先打通:

`阅读分析 -> 可信词汇等级 -> 目标等级分层 -> 生词留存 -> 导出 / 复习`

## 三、当前地基问题

现有 `WordAnalysis.difficulty` 不能作为产品级 JLPT 等级来源:

- 字段由 AI 自由生成,运行时校验器不检查每个词的等级。
- 不同 prompt 混用 `N1-N5` 与 `beginner/intermediate/advanced`。
- 阅读模式硬编码排除 N5,调用方无法得到完整词汇后再分层。
- 多个 UI 的颜色映射和过滤语义不一致。

新版 JLPT 官方不发布逐词的词汇、汉字和语法清单。因此产品可以提供有来源、可复现的社区参考等级,但不能声称它是官方定级。官方说明:

https://www.jlpt.jp/tw/reference/pdf/guidebook_s_e.pdf

## 四、已确认的产品决策

1. **准确性优先**:先完成确定性词表校准,再做目标等级 UI。
2. **本地静态数据**:词表随应用发布;正常构建和运行不调用第三方词典 API。
3. **等级措辞**:界面继续显示「JLPT 等级」,来源页明确说明它来自社区参考数据而非官方清单。
4. **未命中策略**:词表未命中时显示「未定级」,继续展示,不回退到 AI 估级。
5. **目标等级语义**:以目标 N4 为例,N5 是基础词,N4 是重点词,N3-N1 是超纲词,未定级单独保留。
6. **默认目标**:新用户默认 N4。
7. **首轮只覆盖词汇**:没有可信语法数据前,不提供精确的语法 N1-N5 分级。

## 五、里程碑路线图

| 里程碑 | 状态 | 独立交付目标 | 完成定义 |
|---|---|---|---|
| M1:个人生词本 | 已完成 | 从共用词汇卡收藏,在 `/words` 查看和删除 | 收藏状态实时同步;刷新后保留;纯函数测试覆盖 |
| M2A:词汇等级校准地基 | 已完成 | 固定版本词表、确定性匹配、统一数据契约、旧数据重新校准、来源说明 | UI 不再把 AI `difficulty` 当作权威等级;未命中稳定为未定级;旧缓存和收藏零丢失 |
| M2B:目标等级体验 | 已完成 | N1-N5 设置及基础/重点/超纲/未定级四类展示 | 默认 N4;图片分析和 Mokuro 共用设置;刷新后保持 |
| M3:Anki 兼容导出 | 下一步 | 先交付可导入 Anki 的 CSV/TSV | 字段、编码、转义和批量导出可验证;直接 `.apkg` 不在首版 |
| M4:基础 SRS | 待设计 | 为已收藏词增加复习状态和调度 | 调度逻辑可单测;不依赖账号或云同步 |
| M5:语法等级与收藏 | 待研究 | 独立评估语法参考数据、来源和授权 | 未验证数据来源前不进入实现 |

依赖顺序:

`M1 -> M2A -> M2B -> M3 -> M4`

M5 复用 M2A 的数据版本、来源和校准方法,但必须单独设计。汉字、ruby、听力、读解题、模拟测验、账号和云同步保留为后续候选,不进入当前主线。

## 六、M2A 验收门槛

- 固定上游提交、许可证、生成统计、数据版本和摘要均可追踪。
- 等级匹配只使用词形和读音的确定性规则;禁止仅凭读音或 AI 回退。
- 跨等级冲突使用统一规则解决并输出统计。
- 新分析、Mokuro 旧缓存和生词本旧数据都经过同一校准层。
- 数据加载失败时分析和收藏仍可用,新词显示未定级,已有可靠等级不被覆盖。
- 旧缓存无需重新调用 AI,旧收藏数量、原句和时间保持不变。
- 通过单元测试、lint、生产构建、Netlify 运行时代码检查和桌面/移动端手动验证。
